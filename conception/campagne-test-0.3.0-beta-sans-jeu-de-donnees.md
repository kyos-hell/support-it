> Deuxième campagne, après `campagne-test-0.3.0-beta.md` (jeu de données
> « Exemple SAS », 2026-09-19 → 2026-09-20, écarts E1–E18 corrigés sauf E6,
> O6). Celle-ci joue le parcours d'un **client** : dépôt fraîchement cloné,
> `install.ps1` sans option, `installation/` créée par `init`, contexte vide,
> base vide, puis les premiers tickets. Rien n'est corrigé pendant la
> campagne : on teste, on consigne.

Env de test : `C:\Projet-IT\support-it-test` (commit `859ffec`, copie de l'env de dev sans `installation/`). Env de développement : `C:\Projet-IT\support-it`
(branche `v0.3.0-beta`, `859ffec` au départ), **qui garde sa propre
installation** — c'est le test réel d'E18 (deux installations sur un

joue **sans aider le modèle** et colle la sortie ; le QA vérifie les
fichiers, consigne, puis donne la suivante. Verdicts : vert / rouge / refus
injustifié / non joué. Aucune correction dans `produit/` ni dans les
autres docs pendant la campagne.
